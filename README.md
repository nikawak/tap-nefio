# Тап. — мини-сайты для NFC-меток

У одного домена есть панель управления по адресу `/admin` и отдельный адрес для каждого заведения, например `/moka-coffee`. Публичная страница открывается без учётной записи после публикации на общедоступном домене.

## Локальное демо

Требуется Node.js 22.13 или новее. Устанавливать зависимости не нужно.

```powershell
npm run dev
```

Откройте [панель](http://127.0.0.1:4173) или [страницу Moka Coffee](http://127.0.0.1:4173/moka-coffee). Через меню профиля можно переключиться между владельцем и администратором кофейни. Демоданные и изменения сохраняются в `.data/demo.sqlite`.

## Работа с заведениями

1. Владелец создаёт мини-сайт и задаёт его адрес, оформление, ссылки на отзывы и соцсети. Логотип и обложку можно выбрать на устройстве, перетащить в форму или указать ссылкой. Блок «Карты и соцсети» выводит сохранённые ссылки на главной и внизу меню.
2. Во вкладке «Доступ» владелец назначает администратора и сохраняет имя, фамилию, email, белорусский номер и, при наличии, ник в Telegram. Администратор входит по назначенному email или номеру.
3. Во вкладке «Меню» владелец и администратор могут добавлять, изменять, скрывать и удалять позиции. Фото можно выбрать или перетащить в форму позиции. Чтобы переставить позиции, перетащите строку за ручку или нажмите «Выше» либо «Ниже».
4. После публикации страницы владелец или администратор копирует «Ссылку для NFC-метки» и записывает её на метку целиком, вместе с параметром `nfc`.

Основной формат ссылки — `/имя-сайта?nfc=код`. Адреса `/имя-сайта/nfc=код`, `/nfc=код` и `/?nfc=код` переходят на тот же мини-сайт. Если сайт в черновике, владелец и назначенные администраторы могут проверить рабочий код в режиме предпросмотра. Для гостей NFC-ссылка становится доступна после публикации страницы.

В разделе «Настройки» владелец может отдельно включить время работы и гостевой Wi-Fi. Включённые блоки показываются на главной странице. Выключение сохраняет ранее введённый график, имя сети и пароль в настройках.

Через «Оценить заведение» гости могут выбрать оценку от 1 до 5. При оценке от 1 до 3 можно отправить приватный комментарий заведению. Имя и место гость указывает по желанию. Настроенная ссылка на отзывы в картах доступна при любой оценке. Владелец и назначенные администраторы видят приватные сообщения во вкладке «Отзывы» со счётчиком непрочитанных, сортировкой и фильтрами.

Статистика учитывает открытия страницы, включая повторные, и переходы по кнопкам меню, отзывов и соцсетей. Переход к отзывам фиксируется при нажатии на кнопку. Отправку отзыва обрабатывает выбранный картографический сервис. Дни рассчитываются по часовому поясу Europe/Minsk. Владелец видит сводку по всем сайтам, а администратор — только по назначенным ему.

## Развёртывание

```powershell
npm run build
```

Сборка создаёт Worker `dist/server/index.js` для Sites. D1 подключается как `DB`, миграции хранятся в `drizzle/`. Для NFC-страниц требуется общедоступный режим Site. Адреса заведений и NFC-ссылки используют домен, на котором открыта панель.

### Вход через Google

1. В Google Cloud создайте OAuth-клиент типа «Веб-приложение». В список разрешённых адресов перенаправления добавьте `https://tap-panel-nfc.epicaudio3.chatgpt.site/auth/google/return`. Для подключённого собственного домена добавьте его адрес с тем же путём `/auth/google/return`.
2. В настройках среды Sites задайте `GOOGLE_CLIENT_ID` и добавьте `GOOGLE_CLIENT_SECRET` как секрет. Примените эти переменные к рабочему развёртыванию. Кнопка включается, когда заданы оба значения.
3. Укажите Gmail или Google Workspace владельца в `OWNER_EMAIL`. Для второго адреса владельца можно задать `OWNER_SECOND_EMAIL` в том же файле окружения. Оба адреса открывают одну панель владельца. Назначенные администраторы входят с адресом из вкладки «Доступ» и видят свои мини-сайты. Если OAuth-приложение в режиме тестирования, добавьте эти аккаунты в тестовые пользователи Google Cloud.

Интеграция использует Google OpenID Connect. Сервис получает подтверждённый email и имя для входа. Подробнее о параметрах клиента в [документации Google](https://developers.google.com/identity/openid-connect/openid-connect).

### Вход по телефону и через мессенджеры

- В `OWNER_PHONE` можно указать номер владельца в формате `+375XXXXXXXXX`. Номера для входа администраторов задаются в карточках доступа. У прежних назначений сохраняется вход через Google, телефон можно добавить при редактировании.
- Для SMS и Viber задайте `MESSAGGIO_LOGIN` (Bulk Login проекта), `PHONE_CODE_SECRET` (32 случайных байта в Base64URL) и код отправителя выбранного канала в `MESSAGGIO_SMS_SENDER` или `MESSAGGIO_VIBER_SENDER`. Для Viber согласуйте транзакционный шаблон «Тап. Код входа: [код]». Срок кода составляет пять минут. [Отправка сообщений в Беларусь](https://messaggio.com/ru/messaging/belarus/)
- Для Telegram задайте `TELEGRAM_CLIENT_ID` и `TELEGRAM_CLIENT_SECRET` из BotFather. Добавьте `https://nefio.site/auth/telegram/return` в разрешённые URL. Вход использует подтверждённый номер из Telegram. [Telegram Login](https://core.telegram.org/bots/telegram-login)

В рабочей среде храните эти настройки вместе с OAuth-настройками в закрытом файле окружения. Каждый способ появляется в панели после настройки соответствующих параметров.

### Вход с паролем на nefio.site

Владелец входит через Google или Telegram и в меню профиля открывает «Логин и пароль». Для администратора владелец открывает его карточку во вкладке «Доступ» и выбирает «Настроить вход с паролем». Пароль задаётся для адреса почты и действует во всех назначенных сайтах. Дополнительный логин можно оставить пустым.

На экране входа кнопка «Войти с паролем» открывает форму. В ней можно указать почту или настроенный логин. Пароли хранятся в виде хешей. Смена или отключение пароля завершает предыдущие сессии, открытые с этим паролем.

### Запуск на своём сервере

1. Установите Node.js 22.13 или новее и скопируйте исходники. Разместите `tap.sqlite` и папку `menu-photos` в закрытом каталоге данных вне публичной папки. Если получен снимок с `database.json` и фотографиями, выполните `node scripts/import-snapshot.mjs /путь/к/снимку` для создания `tap.sqlite`.
2. Задайте `TAP_PUBLIC_ORIGIN` (например, `https://nefio.site`), `TAP_DATA_DIR` (абсолютный путь к данным), `OWNER_EMAIL` (Gmail или Google Workspace), `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`. В Google Cloud зарегистрируйте адрес сайта с путём `/auth/google/return`. Если переносятся зашифрованные настройки чаевых, сохраните и задайте исходный `TIP_ENCRYPTION_KEY`.
3. Запустите `npm start` через диспетчер служб сервера. Приложение слушает `127.0.0.1:4173`, порт можно задать через `PORT`. Публичный HTTPS обслуживает прокси, который передаёт запросы на этот локальный адрес.

На своём сервере владелец входит через Google по адресу из `OWNER_EMAIL` или `OWNER_SECOND_EMAIL`, администраторы — по адресам, назначенным в заведениях. После переноса нужно заново войти. Перед переключением DNS проверьте меню, фотографии, гостевую NFC-ссылку и сохранение изменений в панели на тестовом адресе. Повторите выгрузку при переключении, если рабочие данные изменились после первого снимка.

## Ссылка и импорт меню

Кнопка «Открыть меню» скрыта по умолчанию. Владелец и назначенный администратор могут включить её через «Меню» → «Настройки меню». Если указать внешнюю HTTPS-ссылку, кнопка будет вести на этот адрес с учётом перехода в статистике. Пустая ссылка открывает меню «Тап.». Позиции и прямой адрес меню сохраняются при скрытии кнопки.

При создании мини-сайта и во вкладке «Настройки» раздел «Ссылки для гостей» управляет видимостью официального сайта, карт и соцсетей. Карты появляются после явного включения чекбокса. Поле адреса появляется при включении пункта. Отключённая ссылка скрывается от гостей, а её сохранённый адрес остаётся в настройках. Для официального сайта нужна HTTPS-ссылка. Все изменения сохраняются одной кнопкой внизу формы.

Через «Импорт из файла» загрузите [шаблон JSON](public/menu-template.json) с подготовленными позициями. В каждой позиции обязательны `name`, `category` и `price`. Цена указывается в основных единицах валюты, например `"5.50"` для 5 рублей 50 копеек. `description` необязательно. По умолчанию позиция видима. Чтобы скрыть её, укажите `"available": false`. Необязательное поле `currency` на уровне файла должно совпадать с валютой мини-сайта.

Один файл может содержать до 500 позиций и занимать до 512 КБ. Импорт добавляет позиции к существующим и пропускает повторную загрузку того же списка. Ошибка в позиции отменяет весь импорт. При активной внешней ссылке гостям продолжит открываться внешнее меню.

Если исходный сайт содержит разметку Schema.org `MenuItem` с ценами, конвертируйте публичную HTTPS-страницу или локальный HTML/JSON-LD в такой же файл.

```bash
node scripts/parse-menu.mjs "https://example.com/menu" menu.json
node scripts/parse-menu.mjs "saved-menu.html" menu.json
```

Проверьте итоговые позиции и цены перед загрузкой. Для PDF, фото, сканов и страниц без разметки подготовьте позиции по тому же шаблону.
