# Тап. — мини-сайты для NFC-меток

У одного домена есть панель управления по адресу `/admin` и отдельный адрес для каждого заведения, например `/moka-coffee`. Публичная страница открывается без учётной записи после публикации на общедоступном домене.

## Локальное демо

Требуется Node.js 22.13 или новее. Устанавливать зависимости не нужно.

```powershell
npm run dev
```

Откройте [панель](http://127.0.0.1:4173) или [страницу Moka Coffee](http://127.0.0.1:4173/moka-coffee). Через меню профиля можно переключиться между владельцем и администратором кофейни. Демоданные и изменения сохраняются в `.data/demo.sqlite`.

## Работа с заведениями

1. Владелец создаёт мини-сайт и задаёт его адрес, оформление, ссылки на отзывы и соцсети. Для логотипа и обложки можно указать ссылки на изображения.
2. Во вкладке «Доступ» владелец добавляет email администратора. Администратор использует этот же адрес при входе через ChatGPT или Google.
3. Во вкладке «Меню» владелец и администратор могут добавлять, изменять, скрывать и удалять позиции.
4. После публикации страницы владелец или администратор копирует «Ссылку для NFC-метки» и записывает её на метку целиком, вместе с параметром `nfc`.

Основной формат ссылки — `/имя-сайта?nfc=код`. Адреса `/имя-сайта/nfc=код`, `/nfc=код` и `/?nfc=код` переходят на тот же мини-сайт. Если сайт в черновике, владелец и назначенные администраторы могут проверить рабочий код в режиме предпросмотра. Для гостей NFC-ссылка становится доступна после публикации страницы.

Статистика учитывает открытия страницы, включая повторные, и переходы по кнопкам меню, отзывов и соцсетей. Переход к отзывам фиксируется при нажатии на кнопку. Отправку отзыва обрабатывает выбранный картографический сервис. Дни рассчитываются по часовому поясу Europe/Minsk. Владелец видит сводку по всем сайтам, а администратор — только по назначенным ему.

## Развёртывание

```powershell
npm run build
```

Сборка создаёт Worker `dist/server/index.js` для Sites. Рабочая база D1 подключается как `DB`, миграции хранятся в `drizzle/`. Переменная `OWNER_EMAIL` определяет владельца панели. Вход через ChatGPT использует идентификацию Sites. Для NFC-страниц требуется общедоступный режим Site. Собственный домен подключается к Sites с подтверждением DNS. Адреса заведений и NFC-ссылки используют домен, на котором открыта панель.

### Вход через Google

1. В Google Cloud создайте OAuth-клиент типа «Веб-приложение». В список разрешённых адресов перенаправления добавьте `https://tap-panel-nfc.epicaudio3.chatgpt.site/auth/google/return`. Для подключённого собственного домена добавьте его адрес с тем же путём `/auth/google/return`.
2. В настройках среды Sites задайте `GOOGLE_CLIENT_ID` и добавьте `GOOGLE_CLIENT_SECRET` как секрет. Примените эти переменные к рабочему развёртыванию. Кнопка включается, когда заданы оба значения.
3. Войдите с адреса Gmail или Google Workspace, который указан как `OWNER_EMAIL` или добавлен во вкладке «Доступ». Если OAuth-приложение в режиме тестирования, проверьте доступ этого аккаунта в Google Cloud.

Интеграция использует Google OpenID Connect. Сервис получает подтверждённый email и имя для входа. Подробнее о параметрах клиента в [документации Google](https://developers.google.com/identity/openid-connect/openid-connect).
