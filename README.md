# Тап. — мини-сайты для NFC-меток

У одного домена есть панель управления по адресу `/admin` и отдельный адрес для каждого заведения, например `/moka-coffee`. Публичная страница открывается без учётной записи после публикации на общедоступном домене.

## Локальное демо

Требуется Node.js 22.13 или новее. Устанавливать зависимости не нужно.

```powershell
npm run dev
```

Откройте [панель](http://127.0.0.1:4173) или [страницу Moka Coffee](http://127.0.0.1:4173/moka-coffee). Через меню профиля можно переключиться между владельцем и администратором кофейни. Демоданные и изменения сохраняются в `.data/demo.sqlite`.

## Работа с заведениями

1. Владелец создаёт мини-сайт и задаёт его адрес, оформление, ссылки на отзывы и соцсети. Для логотипа и обложки можно указать ссылки на изображения.
2. Во вкладке «Доступ» владелец добавляет email администратора. Для входа администратор использует этот же email в ChatGPT.
3. Во вкладке «Меню» владелец и администратор могут добавлять, изменять, скрывать и удалять позиции.
4. После публикации страницы владелец или администратор копирует «Ссылку для NFC-метки» и записывает её на метку целиком, вместе с параметром `nfc`.

Статистика учитывает открытия страницы, включая повторные, и переходы по кнопкам меню, отзывов и соцсетей. Переход к отзывам фиксируется при нажатии на кнопку. Отправку отзыва обрабатывает выбранный картографический сервис. Дни рассчитываются по часовому поясу Europe/Minsk. Владелец видит сводку по всем сайтам, а администратор — только по назначенным ему.

## Развёртывание

```powershell
npm run build
```

Сборка создаёт Worker `dist/server/index.js` для Sites. Рабочая база D1 подключается как `DB`, миграция схемы находится в `drizzle/0000_initial.sql`. В настройках развёртывания переменная `OWNER_EMAIL` определяет владельца панели. Для входа используются заголовки идентификации самого Sites. Для NFC-страниц требуется общедоступный режим Site. Собственный домен подключается к Sites с подтверждением DNS; адреса заведений и NFC-ссылки автоматически используют домен, на котором открыта панель.
