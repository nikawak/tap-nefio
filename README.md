# Тап. — мини-сайты заведений для NFC-меток

«Тап.» позволяет вести несколько заведений с одного домена. У каждого мини-сайта свой адрес. Гость открывает его по ссылке или NFC-метке и пользуется страницей без регистрации.

[Панель управления](https://nefio.site/admin/sites) · [Демо «Кофе 01»](https://nefio.site/coffe1) · [Демо барбершопа «Контур»](https://nefio.site/barbershop) · [О проекте](https://nefio.site/about)

## Панель управления

| Роль | Возможности |
| --- | --- |
| Владелец платформы | Создаёт и публикует мини-сайты, управляет брендингом, ссылками, чаевыми и назначениями администраторов. Видит статистику по всем заведениям. |
| Администратор заведения | Редактирует меню, услуги, оформление и гостевые настройки назначенных мини-сайтов. В главном меню видит бронирования, отзывы, чаевые и аналитику своих заведений. |
| Гость | Открывает опубликованный мини-сайт и пользуется включёнными функциями. |

Мини-сайт создаёт владелец. Он задаёт адрес, оформляет страницу и может назначить администраторов во вкладке «Доступ». После публикации скопируйте ссылку для NFC-метки из карточки заведения. Сохраните весь адрес, включая параметр `nfc`.

Основной формат NFC-ссылки — `/имя-сайта?nfc=код`. Один код относится к одному мини-сайту. Если записать одну ссылку на несколько меток, они учитываются вместе. Владелец и назначенные администраторы могут открыть черновик в предпросмотре. Статистика считает повторные открытия, различает NFC и обычные переходы и показывает данные за 7, 14 или 30 дней по времени Минска.

## Гостевая страница

Во вкладке «Для гостей» можно менять порядок элементов. Меню, услуги, официальный сайт, график работы, Wi-Fi, соцсети, отзывы, бронирование и чаевые появляются в зависимости от настроек заведения. В «Оформлении» доступны 25 тем. Владелец задаёт логотип и обложку в настройках мини-сайта.

- **Отзывы.** В карточке мини-сайта откройте «Для гостей» → «Настройки отзывов». Включите кнопку «Оценить заведение» и добавьте хотя бы одну ссылку на Яндекс или Google. Гости с оценкой от 1 до 3 могут отправить приватный комментарий. В главном разделе «Отзывы» можно выбирать заведение и отмечать отзывы прочитанными.
- **Wi-Fi.** Гость открывает блок, видит название сети и может скопировать пароль. При выключении графика или Wi-Fi введённые данные сохраняются.
- **Чаевые.** В одноимённом разделе главного меню видны переходы по платёжным ссылкам и подтверждённые оплаты bePaid. Владелец может выбрать заведение и настроить способы приёма. [Настройка чаевых в Беларуси](docs/tips-belarus.md)

### Бронирование столиков

1. Откройте карточку мини-сайта → «Для гостей» → «Настройки бронирования». Отметьте «Принимать заявки на бронирование» и сохраните. Переключатель доступен владельцу и назначенным администраторам. По умолчанию приём заявок выключен.
2. На опубликованной странице гость нажимает «Забронировать столик» и указывает дату, время по Минску, количество гостей, имя и телефон. Комментарий можно оставить по желанию.
3. Новая заявка появляется в разделе «Бронирование» главного меню. Можно фильтровать заявки по заведению и статусу. Проверьте наличие места, подтвердите или отклоните заявку и сообщите решение гостю по указанному телефону. Подтверждённую бронь можно отменить.

Выключение приёма скрывает кнопку и закрывает отправку новых заявок. Ранее полученные заявки доступны для просмотра и обработки. В предпросмотре можно открыть форму без отправки заявки.

## Ссылка и импорт меню

Вкладка «Меню» позволяет редактировать категории, названия, описания, цены, видимость и фотографии позиций. Чтобы изменить порядок, перетащите строку либо используйте кнопки «Выше» и «Ниже». Если позицию успел изменить другой сотрудник, панель попросит проверить свежие данные перед повторным сохранением.

Во вкладке «Услуги» доступен отдельный каталог с теми же полями и возможностями редактирования. Кнопки «Открыть меню» и «Смотреть услуги» включаются независимо. Панель категорий остаётся вверху при прокрутке обоих гостевых каталогов. В «Аналитике» открытия меню и услуг считаются вместе.

Через «Настройки меню» включите гостевую кнопку «Открыть меню». Если задана внешняя HTTPS-ссылка, кнопка ведёт на неё. Чтобы открыть встроенное меню, оставьте поле ссылки пустым. При отключении кнопки позиции и прямой адрес меню сохраняются.

Чтобы добавить список позиций, выберите «Импорт из файла» в нужной вкладке. В каждой позиции нужны поля `name`, `category` и `price`. Цена указывается в основных единицах валюты, например `"5.50"` для 5 рублей 50 копеек. Поля `description` и `available` необязательны. Значение `"available": false` скрывает позицию. Если указана валюта `currency`, она должна совпадать с валютой мини-сайта. [Шаблон меню](public/menu-template.json) · [Шаблон услуг](public/service-template.json)

Импорт добавляет до 500 позиций из файла размером до 512 КБ. Повторная загрузка того же списка пропускается. Ошибка в любой позиции отменяет импорт. HTML или JSON-LD с разметкой Schema.org `MenuItem` можно преобразовать в файл импорта.

```bash
node scripts/parse-menu.mjs "https://example.com/menu" menu.json
node scripts/parse-menu.mjs "saved-menu.html" menu.json
```

## Локальная разработка

Требуется Node.js 22.13 или новее. Сторонние зависимости устанавливать не нужно.

```bash
npm run dev
```

После запуска откройте [локальную панель](http://127.0.0.1:4173/admin) или [страницу Moka Coffee](http://127.0.0.1:4173/moka-coffee). В профиле можно переключиться между владельцем и администратором кофейни. Локальные изменения сохраняются в `.data/demo.sqlite`, загруженные изображения — в `.data/menu-photos/`.

В отдельном терминале можно запустить тесты и сборку.

```bash
node --test
npm run build
```

| Путь | Назначение |
| --- | --- |
| `public/` | Интерфейс панели, гостевых страниц и страницы о проекте |
| `src/worker.js` | API, гостевые маршруты, вход и бизнес-логика |
| `drizzle/` | Миграции SQLite и D1 |
| `scripts/` | Локальный запуск, сборка, импорт снимка и публикация |
| `test/` | Проверки прав доступа, меню, статистики и бронирования |

## Развёртывание

### Запуск на своём сервере

1. Установите Node.js 22.13 или новее и скопируйте исходники. Задайте `TAP_PUBLIC_ORIGIN` с публичным HTTPS-адресом и `TAP_DATA_DIR` с абсолютным путём к закрытому каталогу. В нём хранятся `tap.sqlite` и каталог `menu-photos/`. Миграции применяются при запуске.
2. Настройте вход владельца и администраторов. При переносе настроек чаевых задайте исходный `TIP_ENCRYPTION_KEY`.
3. Запустите `npm start` через диспетчер служб сервера. По умолчанию приложение слушает `127.0.0.1:4173`. Чтобы изменить порт, задайте `PORT`. Публичный HTTPS обслуживает обратный прокси.

Снимок с `database.json` и изображениями можно импортировать командой `node scripts/import-snapshot.mjs /путь/к/снимку`. После переноса пользователи входят заново. Для полной резервной копии сохраняйте базу, загруженные изображения и ключ шифрования чаевых.

В репозитории настроен workflow `Verify Tap`. Он запускает тесты для `main` и pull request. Для Hoster.by предусмотрен ручной запуск с операциями `check` и `publish`. Автопубликация при обновлении `main` управляется переменной `HOSTER_AUTO_DEPLOY`. Публикация готовит резервную копию SQLite, проверяет новый процесс и возвращает предыдущий релиз при сбое проверки.

### Сборка для Sites

`npm run build` создаёт Cloudflare Worker `dist/server/index.js`. В `.openai/hosting.json` указаны существующий Site и привязки D1 (`DB`) и R2 (`BUCKET`). Перед запуском нового кода примените миграции из `drizzle/` к этой базе. Для гостевого доступа по NFC нужен общедоступный режим Site.

### Вход через Google

Создайте OAuth-клиент типа «Веб-приложение» и добавьте `/auth/google/return` на каждом домене, где будет доступен вход. Например, `https://nefio.site/auth/google/return`. Если приложение Google находится в режиме тестирования, добавьте нужные аккаунты в список тестовых пользователей.

- `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` включают кнопку Google.
- `OWNER_EMAIL` задаёт адрес владельца. `OWNER_SECOND_EMAIL` позволяет добавить второй подтверждённый адрес.
- Администратор входит с адресом из вкладки «Доступ». Права применяются по текущим назначениям.

### Вход по телефону и через мессенджеры

Для входа по телефону владелец указывает `OWNER_PHONE`. Номера администраторов задаются в карточках доступа. Используются белорусские номера `+375XXXXXXXXX`.

- **SMS и Viber.** Задайте `MESSAGGIO_LOGIN`, `PHONE_CODE_SECRET` (32 случайных байта в Base64URL) и отправителя в `MESSAGGIO_SMS_SENDER` или `MESSAGGIO_VIBER_SENDER`. Для Viber согласуйте транзакционный шаблон. Код действует пять минут.
- **Telegram.** Задайте `TELEGRAM_CLIENT_ID` и `TELEGRAM_CLIENT_SECRET` из BotFather. Зарегистрируйте `/auth/telegram/return` на используемом домене. Вход использует подтверждённый номер из Telegram.

### Вход с паролем

На самостоятельном хостинге с HTTPS владелец может задать пароль в меню профиля «Логин и пароль». Для администратора владелец открывает его карточку во вкладке «Доступ». После настройки можно входить по email или дополнительному логину. Смена или отключение пароля завершает предыдущие сессии, открытые с этим паролем.

Переменные окружения с секретами хранятся в защищённых настройках хостинга. [История решений и контекст проекта](docs/project-context.md)
