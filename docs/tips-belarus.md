# Чаевые для мини-сайтов в Беларуси

Владелец настраивает способы во вкладке «Чаевые» нужного заведения. Для каждого включённого способа указывается получатель. Если включена одна готовая ссылка, кнопка сразу открывает её. При нескольких способах гость выбирает получателя и вариант оплаты из списка.

## Готовые платёжные ссылки

| Способ | Что указать в панели |
| --- | --- |
| «нетмонет» Альфа-Банка | Ссылку на страницу чаевых получателя из его QR-кода. Поддерживаются адреса на домене `alfabank.by` и его поддоменах. [Описание Альфа-Банка](https://www.alfabank.by/netmonet/) |
| MoneyApp БСБ Банка | Ссылку сбора, созданного получателем. Поддерживаются адреса на домене `bsb.by` и его поддоменах. [Описание БСБ Банка](https://t.me/s/bsb_bank?before=191) |
| «Чай-код» Беларусбанка | Прямую HTTPS-ссылку из QR-кода на домене `belarusbank.by` или его поддоменах. Ссылку стоит открыть на смартфоне до включения. [Описание Беларусбанка](https://t.me/s/belarusbank_channel?before=3359) |
| Платёжная ссылка bePaid | Ссылку, созданную в кабинете bePaid. Поддерживаются адреса на домене `bepaid.by` и его поддоменах. [Управление ссылками](https://docs.bepaid.by/ru/integration/pay_by_link/) |

Для готовых ссылок отчёт считает переходы по каждому способу, в том числе с NFC-меток. Данные об оплатах по этим ссылкам доступны у платёжного провайдера.

## bePaid с вводом суммы

1. Получите в bePaid доступ для магазина, которому разрешено принимать чаевые. В панели «Тап.» укажите получателя, ID магазина, секретный ключ и публичный RSA-ключ из кабинета bePaid.
2. Проверьте перевод в тестовом режиме. Гость вводит сумму от 1 до 300 BYN и продолжает на странице bePaid.
3. После проверки включите рабочий режим. Провайдер принимает реквизиты карты и направляет подписанное уведомление. «Тап.» сверяет подпись, идентификатор, сумму и валюту, затем добавляет оплату в отчёт. Тестовые платежи учитываются только в статусе конкретной операции.

Секретный ключ магазина хранится в зашифрованном виде. Переменная среды Sites `TIP_ENCRYPTION_KEY` содержит 32 случайных байта в Base64URL и используется для шифрования ключей магазинов и защиты формы оплаты. При отдельном развёртывании её нужно задать до подключения bePaid. Сохраните действующий ключ среды при обновлениях, чтобы сохранённые ключи магазинов оставались доступны.

[Создание платежа bePaid](https://docs.bepaid.by/ru/integration/widget/payment_token/) · [Проверка уведомлений bePaid](https://docs.bepaid.by/ru/using_api/webhooks/)

## Прямой API «нетмонет»

Альфа-Банк подтверждает возможность интеграции на сайте. Для реализации нужны спецификация API белорусской версии и доступ к её тестовому контуру. Публичная страница ведёт к заявке на подключение. Готовая платёжная ссылка «нетмонет» доступна как отдельный способ. [Подключение Альфа-Банка](https://www.alfabank.by/netmonet/)
