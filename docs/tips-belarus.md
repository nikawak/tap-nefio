## План подключения после выбора

1. Зафиксировать, куда поступают чаевые у каждого заведения. Варианты получателя — сотрудник, команда или заведение при согласованной с провайдером схеме. Для первого запуска достаточно одного получателя на мини-сайт.
2. Владелец настраивает провайдера и получателя в панели. На опубликованной странице появляется кнопка «Оставить чаевые» после заполнения настроек. Реквизиты карт вводятся на стороне платёжного провайдера.
3. Для готовой HTTPS-ссылки использовать тот же серверный переход, что и для остальных действий лендинга. Перед перенаправлением записывать событие открытия страницы чаевых с привязкой к заведению и источнику визита.
4. Для варианта с API хранить идентификатор платежа, сумму в копейках, валюту BYN и статус. Засчитывать успешную оплату по проверенному уведомлению провайдера или подтверждению через его API. Повторное уведомление по тому же платежу учитывается один раз.
5. Проверить сценарий на телефоне с NFC-меткой, получателя, сумму и комиссию, успешную оплату и отмену. Для отчётов предусмотреть счётчик открытий страницы чаевых и отдельные показатели по подтверждённым платежам при наличии статуса от провайдера.
